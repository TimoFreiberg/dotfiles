name: writing-skills
description: "Use when writing, editing, or trimming a skill or other agent instructions."
---

A skill gives a capable agent a procedure it wouldn't otherwise follow. It is
not the place to make the agent careful or thorough: it already tries to be,
and checklists of quality dimensions crowd out the procedure and get followed
to the letter.

Before writing, agree with the operator on what is essential: the steps, the
decision points, what gets handed between agents, and the conventions only
this setup has. Everything else is a candidate for deletion. Then find the
shortest phrasing that stays accurate, going back and forth with the
operator.

Write for a reader who is smart and has no context. One sentence that sets a
mindset ("are we going galaxy-brained?") beats a list that spells it out.
Make each decision once and let the rest follow from it, rather than
restating it per case. Leave out what the harness and tools already handle.
Prefer porting a good existing skill over elaborating your own.

When you cut something, say what and why, so the operator can put it back.
